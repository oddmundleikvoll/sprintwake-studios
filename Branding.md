# Sprintwake Studios

The approved route-shaped Sprintwake S is reused from Sprintwake Projects,
at the user's request. Geometry is unchanged. Studios uses a charcoal/plum
background, copper route (#EBA477) and pale-gold endpoint (#F4D5A0).
Editable source: assets/sprintwake-mark.svg and native/icon.m. The native icon
renderer generates the app icon and transparent header mark. Existing Copper
application colors and New York/SFNS typography are retained.

Compatibility identifiers, Keychain service and existing Raven Studio data paths
remain stable; display naming does not move or replace user productions.
